# ParkEn

Find. Reserve. Park.

A smart parking ecosystem that simplifies parking operations for malls, hospitals, airports, corporate campuses, hotels, restaurants, valet services, and event venues.

## Features

- OTP Authentication
- Parking Reservations
- Walk-In Parking
- QR-Based Sessions
- Vehicle Number Lookup
- Corporate Parking
- Valet Management
- Hospital Priority Parking
- Offline Operations
- Occupancy Analytics
- Smart Insights

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- FastAPI
- PostgreSQL

Infrastructure:
- Docker
- Mapbox
